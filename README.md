## 🌟 Features

* **Datamining Alerts**: Simulated webhook features tracking string diffs, GitHub commits, and Discord experiment rollouts (custom Vexil modules).
* **Vexil Ecosystem Shortcuts**: Fetch links to Vexil packages, compilers, and extensions natively.
* **Moderation Tools**: Robust jail, blacklist, mute, and say commands.
* **Interactive Fun**: Play RPS, get jokes, predict relationships with the newly added **FLAMES** game, or self-timeout.
* **Fast Local Sync**: Local command syncing for rapid deployment.

## 🚀 Commands overview

### 🔧 Utility & User

| Command | Description |
| ------- | ----------- |
| `/ping` | Check bot latency |
| `/poll` | Make an interactive poll (max 10 options) |
| `/whoami` | Display rich information about yourself |
| `/whois` | Display rich information about another user |

### 📦 Ecosystem & Repositories

| Command | Description |
| ------- | ----------- |
| `/repo` | Get direct links to Vexil ecosystem repositories |
| `/package` | Get a link to a specific Vexil package from the registry |

### 🛡️ Moderation

| Command | Description |
| ------- | ----------- |
| `/blacklist` | Blacklist a user from interacting with the bot |
| `/unblacklist`| Remove a user from the blacklist |
| `/mute` | Temporarily mute a user |
| `/unmute` | Unmute a restricted user |
| `/say` | Echo a message to a channel |

### 🎮 Fun

| Command | Description |
| ------- | ----------- |
| `/flames` | Play the FLAMES game to predict relationship compatibility! |
| `/rps` | Play Rock, Paper, Scissors |
| `/joke` | Fetch a random programming/general joke |
| `/self-timeout`| Timeout yourself for a specified duration |

### 🛠️ Vexil Custom Modules (Datamining)

We have built specific commands simulating the highly-requested Datamining webhooks seamlessly wrapped in the Vexil aesthetic:

| Command | Description |
| ------- | ----------- |
| `/datamining_string` | Triggers a **String Occurences Changed** diff embed |
| `/datamining_commit` | Triggers a **GitHub Commit Comment** notice embed |
| `/datamining_rollout`| Triggers a **Guild Experiment Rollout** notice embed |

### 👑 Owner

| Command | Description |
| ------- | ----------- |
| `/shutdown` | Safely shutdown Vexil |
| `/restart` | Restart Vexil |
